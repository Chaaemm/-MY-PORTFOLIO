MY PORTFOLIO - เวอร์ชันปรับปรุง
ธีม: ฟ้า / ขาว / ชมพู | ฟอนต์ไทยทรงมน | รองรับมือถือ

วิธีเปิดดู:
1) แตกไฟล์ ZIP
2) เปิดโฟลเดอร์ portfolio_neramit
3) ดับเบิลคลิก index.html

การใส่รูป:
- กดปุ่ม “เลือกรูปโปรไฟล์” เพื่อเลือกรูปโปรไฟล์
- ในส่วนผลงาน กดกรอบ “เพิ่มภาพผลงาน” เพื่อเปลี่ยนภาพในแต่ละช่อง
- กด “เพิ่มรูปหลายภาพ” เพื่อเพิ่มภาพหลายรูปในแกลเลอรี
- การเลือกรูปเป็นการแสดงตัวอย่างในเบราว์เซอร์ปัจจุบัน หากต้องการให้ภาพติดไปกับเว็บไซต์ออนไลน์
  ให้คัดลอกไฟล์ภาพไปไว้ในโฟลเดอร์ assets และอัปโหลดไฟล์ภาพพร้อมเว็บไซต์ขึ้น GitHub

การแก้ไขข้อมูล:
- เปิด index.html ด้วย VS Code หรือ Notepad
- แก้ไขชื่อ ประวัติ ช่องทางติดต่อ และข้อความให้เป็นข้อมูลจริง
- หัวข้อปัญหา/ความประทับใจ/ข้อเสนอแนะเป็นข้อความตัวอย่าง ควรแก้ให้ตรงกับประสบการณ์จริง
- ตรวจสอบชื่อผู้ควบคุมการฝึกงานก่อนเผยแพร่

ไฟล์หลัก:
- index.html = เนื้อหาเว็บไซต์
- style.css = สี รูปแบบ ฟอนต์ และการจัดวาง
- script.js = เมนู การแสดงรูป และลูกเล่น
